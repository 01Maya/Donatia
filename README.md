# 💗Donatia — Charity & Nonprofit Landing Page

> A modern, welcoming nonprofit landing page designed to communicate social impact, highlight community initiatives, and encourage people to make a difference.

## ✨ Overview

Donatia is a charity landing page concept focused on **community, compassion, and meaningful change**.  
It combines a clean visual layout, warm imagery, and clear calls to action to present the organization's mission.

---

## 📝 Description

The website introduces Donatia through a friendly, image-led experience with a soft pastel palette and rounded UI elements.  
Visitors can explore the organization's mission, impact statistics, guiding principles, initiatives, testimonials, and recent projects through a structured page flow.  
Smooth scrolling, entrance animations, hover interactions, animated counters, and a curtain-style scroll effect add motion while keeping the experience approachable and easy to follow.

---

## 🚀 Features

- 📱 Responsive layouts for desktop, tablet, and mobile
- 🧭 Section-based navigation
- ✨ Scroll-reveal and entrance animations
- 🎞️ Curtain-style page-scroll animation
- 🔢 Animated impact counters
- 🖱️ Interactive hover states and micro-interactions
- 🌱 Mission and organization overview
- 📊 Impact statistics to highlight progress
- 🤝 Principles and approach section
- 🐾 Image-led initiative cards
- 💬 Testimonials to support trust and credibility
- 🗂️ Recent projects and impact stories
- 🎯 Clear donation and engagement calls to action
- 📐 Consistent spacing, typography, and visual hierarchy
- 🎨 Soft pastel colors and rounded components
- ♿ Thoughtful, accessible interaction patterns

## 🧩 Sections
